# Phi-3.5-MoE 跑主模型的临床测验（计划）

**状态：用户 2026-11-02 选定（方案甲）；代码已写好并在本机小模型上跑通；判读规则在看到任何结果之前写定。**

## 为什么做

Phi-3.5-MoE 是另一家公司的混合专家模型。它没过纳入标准：完好的 Phi 在难题上只答对 39%，低于瞎猜（表 S1）。这是模型本身的性质，再做多少损伤实验也改不了，所以 Phi 在论文里始终是"未过纳入标准的探索性第二模型"。

现在 Phi 只有两组组件的搜索结果（补充材料 S1.1）：控制头让控制效应扩大，提取组件让罕见词的命名受损更重。主模型除此之外还做了第 3.2、3.3 节整套测验：命名与六选一的双分离、词义匹配不受损、回答位置损伤、分级损伤、联合损伤、误导提示的代价。用户希望 Phi 的证据也这样完整，让读者能逐项对照两个模型。结果一致还是不一致由数据决定，跑出什么就写什么。

## 怎么做

只做前向计算，模型权重不变。代码 `experiments/second_model/run_phi_battery.py`，测验与主模型完全相同：同样的 160 个保留概念、同样的提示、同样的打分函数、同样的三种批量布局、同样的均值消融（用 Phi 自己的 WikiText 均值，float16，与 S1.1 相同）。

组件：
- PR6：Phi 提取搜索选出的八个组件去掉两个模型离不开的专家（3:7、5:10）后剩下的六个：专家 26:6、27:8，注意力头 10:5、14:21、17:9、18:26。
- PC4：Phi 控制搜索选出的四个注意力头 0:2、1:1、6:11、6:28。

| 部分 | 状态 | 测什么 |
| --- | --- | --- |
| battery | 完好、PR6、PC4、PR6+PC4、PR6 保留 75%、PC4 保留 75%（全部位置）；PR6、PC4 只在回答位置 | 从定义命名（无提示、示范题带提示、首字母提示、误导提示）、六选一（字母作答与说出词两种）、词义匹配、抄写；全部位置的状态另取生成答案与中性文本损失 |
| random | 完好、PC4 回答位置、20 组随机四头（每组在 PC4 的四个层各取一个头，种子 1910 + i）回答位置 | 误导代价与提示获益的变化 |
| generated | 完好、PR6、PC4 | 240 个保留命名概念上的生成答案（大小写不敏感判分），罕见词与常见词的正确率损失 |
| bias | 完好、PR6、PC4，各带与不带输出偏置 | 240 个保留命名概念的对数概率，量化旧结果漏掉偏置的影响 |

**输出层偏置。** 写代码时发现 Phi 的输出层带偏置（`lm_head_bias: true`，32,064 个值，均值 0.010，标准差 0.019，范围 −0.065 到 0.115 logit），而共享的打分函数只乘输出权重。Qwen 和 OLMoE 没有偏置，不受影响。Phi 旧结果（S1.1）都没加偏置。偏置对同一个词在损伤前后相同，在"损伤前减损伤后"的比较里基本抵消，预计影响在 0.01 nat 量级。这次所有打分都加上偏置（`experiments/second_model/output_bias.py`，冻结的打分模块一个字节不改，测试 `tests/test_output_bias.py`），并用 bias 部分实测旧结果偏了多少。

**题目范围。** 主分析用 160 个概念里完好的 Phi 自己能做对的那些（与主模型同一套规则：六选一里目标的概率最高且不低于门槛算选择合格，无提示命名里目标词胜过联想词算命名合格），另报告全部 160 个概念的结果。

## 判读规则（事先写定，不看结果再改）

每项都与主模型的对应检验比较，区间是按概念重抽样 10,000 次的 95% 区间。"一致"指方向相同且区间满足下面的条件。

1. **命名与六选一的双分离（对应 H2a）**：PR6 的命名损失减 PC4 的命名损失，区间下限大于 0；PC4 的六选一损失减 PR6 的六选一损失，区间下限大于 0。两条都满足算一致。
2. **词义匹配不受损（对应 H2b）**：PR6 的命名损失区间下限大于 0，且它的词义匹配损失区间上限低于 0.73 logit（主模型事先定的可忽略上限）。
3. **回答位置（对应 H2e）**：只在回答位置损伤 PR6，命名损失区间下限大于 0；抄写损失区间包含 0 或绝对值小于 0.20 nat 算"抄写不受影响"。
4. **误导代价（对应 H4d）**：只在回答位置损伤 PC4，误导代价的增加减提示获益的变化，区间下限大于 0；另报告 PC4 在 20 组随机四头中的排位（只描述，不作检验）。
5. **分级（对应 H2d）**：完全损伤比保留 75% 的损伤更伤各自的标记（PR6 看命名、PC4 看六选一），区间下限大于 0。
6. **联合损伤（对应 H4g）**：命名的交互项（联合损失减两项单独损失之和）区间落在 ±0.20 以内算"相加"；六选一交互项区间排除 0 算"有交互"，方向另报。
7. **生成答案的词频效应**：PR6 让罕见词正确率下降得比常见词多，区间下限大于 0 算一致；PC4 同样计算作对照。罕见、常见按 Phi 知识筛选时的 Zipf 中位数划分。
8. **错误类型（对应 H3a）**：只描述，不作检验。

中性文本损失比完好模型高 10% 以上的状态，结果照报但不解释为选择性损伤（与主模型相同）。
