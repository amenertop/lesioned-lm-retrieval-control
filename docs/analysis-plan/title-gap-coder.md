# Qwen3-Coder 的预定复现

2026-10-19，agent3。用户授权完成补实验戊。该模型的损伤结果尚未查看。本文档是内部冻结计划，没有公开预注册。

模型为 Qwen3-Coder-30B-A3B-Instruct，固定 revision `b2cff646eb4bb1d68355c01b18ae02e7cf42d120`。完整权重逐片核对官方摘要。格式及测量门槛沿用 `docs/plans/title-gap-experiments.md` 第 8.1 节，通过后才进入定位。

复现沿用主模型原有控制与命名筛选、扩组及确认入口。中性均值在 Coder 自己的激活上采集。控制筛选在它自己的 M1 找组题上计算全部专家和头的归因，验证前 32 个候选，再依既有排除通用损伤的规则选出四个成员。命名筛选在自己的找组题上计算归因和单成员消融，先选四个，再按既有规则扩至八个。成员坐标不从主模型复制。

开发联合比较各使用 20 组匹配随机损伤，最终的控制与双向分离检验各使用 200 组。计分为 float16，M1 沿用 `prefix_avg3`，命名沿用三种批量组合的平均。sorted 只替代已验证等价的专家计算，记录实际实现。新模型先做一次已有前缀计分核对。若数值检查不通过，保留失败记录并定位原因，不把失败输出混入正式结果。

最终判定、区间、最小有意义效应与非劣效界限沿用现有 `control-test.md` 和 `knowledge-test.md` 所定义的规则及入口。两个组间方向差分别保存，联合判定由两者共同决定。原始条目、两选项顺序、随机组与种子全部保留。没有找到足够合格组件或测量不通过也作为结果，不改标签追求通过。

这些材料在主模型的既有研究中使用过，在 Coder 中仍按原找组、开发和最终划分处理。结果表述为第二模型的预定复现，不称新的未公开刺激集。定位使用的主张是提取与控制的功能分离，跨任务 SD 完整标记另由甲、乙、丁检验。

运行入口为 `experiments/title_gap/run_coder_replication.sh`，接收自己的均值、完好测量结果和冻结标签。冻结标签对应一份干净快照，定位到确认过程中不修改该快照的代码和材料。

运行前核对完好测量的固定版本、权重摘要、精度和三份材料摘要，同时核对独立均值的模型及中性文本。命名材料门槛使用正式命名的三种批量平均，失败则停止命名定位。每个阶段保存完整请求和输出摘要，只有相同来源且输出未变才续用。命名排名与八成员开发结果均锁定，最终成员必须等于实际开发的成员。

最终两个组是否重叠按实际名单报告，不额外强制互斥。命名随机组沿用单批量计算，新增同批量目标的超过计数与经验概率，保留原三批平均目标的历史字段供核对。主要方向差与区间仍用既定平均计分，不因随机比较的来源修复改判据。
