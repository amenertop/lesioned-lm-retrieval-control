# 同形异义词产出的最终检验

2026-10-19，agent3。在最终家族运行前固定。以配套 JSON 的摘要、实际冻结标签与逐状态输出为准。

## 材料和比较

使用已双审的 40 个最终词义家族，每家族两个常模词义、两档语境和三个提示条件。家族及其近形词按原划分隔离。题干、指定联想词和盲判规则沿用开发版本，不按最终输出换题。

保留原 13 个参照状态，加入开发已选的 PC8 全段和回答区损伤，共 15 个核心状态。PC8 的成员与开发选择完整存于 `selections/title-gap-production.json`。它来自 20 个开发家族找组、另 20 个开发家族验组及独立复制检查。原 SC4 结果不被替换。

`homonyms-final-core.json` 固定核心状态。`homonyms-final-pc-random.json` 固定 PC8 与 200 组匹配随机损伤。随机组匹配种类、数量、层、剂量和专家路由频率，种子为 1910，不含目标成员。两个文件的相同完好和 PC8 状态只算一份证据，重复输出须逐项核对。旧参照组在新任务上的随机比较另批按同一规则固定，不能用旧任务的随机分布代替。

## 主要问题与预期方向

主要临床读数是回答是否符合所要求的词义。低支持语境为预定主条件，高支持语境检验语境细节能否改变损伤后果。高低语境改变语义说明的充分程度，不称为单纯的控制操纵。

1. 非优势义是否更容易被另一词义带走。计算非优势义损伤减优势义损伤，并直接比较 PC8 全段与 WR8 全段。预期 PC8 的额外损伤更大。另报明确的另一词义回答，不把重复歧义词当成已知的错义。
2. 正确提示是否更能帮助 PC8。计算非优势义中提示后减提示前的语义正确率，再比较 PC8 全段与 WR8 全段。预期 PC8 的增益更大。两条主要方向一起判断产出侧临床分离，不从中只挑成功的一条。
3. 原 SC4 全段、回答区和提示区的对照，以及 PC8 全段对回答区的差值，检验处理位置。它们完整报告，不能把选中 PC8 本身当作 SC4 已成功迁移。

每组相对完好的变化与两组直接差值并列。语义提示救回率以该组无提示答错的同一批对象作分母，同时保存初始错误数。原两组无提示差别与全部预定剂量曲线一起报告，不根据最终成绩重新寻找最有利的严重度匹配。

指定目标词相对另一词义词的概率优势和二选一分数为不同的次要读数。它们可以揭示词形竞争和提示使用，不能替代自由回答的词义正确率。误导提示伤害、复制、格式与普通文本语言损失分别报告。

## 回答与不确定性

原人类联想词典的文件摘要在配套 JSON 中固定。只有词典初判未分类的回答可以接受新判断，已有词义标签和原样重复歧义词不能由审核表覆盖。新回答交给不知道损伤状态和提示条件的审核者。同一词义下，同一个词的大小写和末尾标点变化共用一个判断，规范化与自动分类使用同一函数。核心状态与随机组统一合并后生成一份队列，记录队列、判断表摘要及真实审核身份。每个新回答都要给出词义判断或明确保留未决，不能静默漏审。指定词命中、空答和格式类别始终按原规则计算，审核者不能改写这些类别。尚无法定类的回答不默认正确或错误。

已完整分类的差值按家族进行一万次配对重抽样，报告百分位 95% 区间。含未决答案时报告绑定回答身份的分类上下界，并在每次家族抽样中重新计算界限。另报下界的 2.5% 分位至上界的 97.5% 分位所组成的外界，明确它同时包含抽样与分类不确定性，不给未决答案虚构一个点估计。恢复比例的零分母保留缺失。

随机比较先展示所有随机组和目标组的实际读数。完整数值的上尾秩为 `(1 + 随机组不小于目标的数量) / 201`，方向在上述问题中固定。未决语义比较使用可保证和可能超过目标的计数范围，不把候选词概率的秩改称语义正确率的秩。随机比较与两组直接差值的含义分开。

最终分析由配套 JSON 提供全部比较和抽样次数，命令行不能删改确认比较。核心状态与随机组缺少任何一批时不能标为完成的确认分析。重复输出、缺失对象、非有限分数或来源不匹配均须先解决，再解释结果。最终结果无论是否支持预期都保留。新机制想法另列为看过结果后的分析，不回写本次判据。
