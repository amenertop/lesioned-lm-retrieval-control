## 1. 检验什么

两项主要检验，都比较控制损伤（C）与知识损伤（K），并且都要超出“整体变弱”对照模型的预测：

- **H3a（错误类型）**：不给选项、不给提示，让模型看定义说词。控制损伤相对于知识损伤，是否更多答成联想词、更少答成分类词（同类词、上位词）。
- **H3b（提示）**：控制损伤相对于知识损伤，是否更依赖首字母提示，也更容易被误导提示带偏。

## 4. 统计量

- 计分同 `lesion.m3_scoring`：Instruct 从助手回答开头开始，整词各 token 的对数概率之和，不含结束标记。每种状态在批量 16、11、7 上各算一次，取平均。
- **H3a**：
  - 五个候选（目标、同类、上位、联想、无关）的对数概率在候选之间做 softmax；
  - S = P(联想) − [P(同类) + P(上位)]；
  - ΔS = S_损伤 − S_完好，D = ΔS_C − ΔS_K，预测为正；
  - 最小有意义效应 0.05。
- **H3b**：
  - Δ = log P(目标) − log P(联想)；
  - R = Δ_线索 − Δ_误导；
  - ΔR = R_损伤 − R_完好，D = ΔR_C − ΔR_K，预测为正；
  - 最小有意义效应 0.20 logit。
- **退化模型**（方案第 5 节）：每类损伤、每个题型用自己的 (T, λ)，以完好模型在正式题上的分数代入，得到预测的 D_pred；超出量 = D_obs − D_pred。
- **区间**：校准概念与正式概念独立重抽样，每次在校准重抽样上重新拟合 (T, λ)；C、K 用同一批重抽样；共 10,000 次，取百分位区间；种子 0。实现：`lesion.e3_analysis.excess_test`。

## 5. 判定

- **支持**：D_obs 的区间不含 0 且为正，并且超出量的区间下界高于 0。超出量小于最小有意义效应时，写成“存在，但很小”。
- **其余为证据不足**，不设“排除”（用户 2026-09-27 决定）。
- **多重比较**：H3a、H3b 用单侧 p 值做 Holm 校正，p =（超出量 ≤ 0 的重抽样次数 + 1）/（10,000 + 1）。H4 若之后进行，再加入同一族。
- **事先说明**：按校准数据，H3a 的超出量约 +0.02，H3b 的 D_obs 为负。用户决定不因此修改预测（Q16），照原样检验、如实报告。

## 6. 敏感性分析与补充结果（只报告，不作判定）

- H3a 的对数尺度版本 S_log、按 token 平均的版本；无关词概率和目标词对数概率的变化。
- H3b 的“提示贡献不变”对照（必然预测 ΔR = 0，所以观测到的 ΔR 及其区间就是它的残差），以及证据加权模型的三个权重 (a, b_cue, b_miscue)（Q19，只在校准题上拟合，再代入正式题）。
- 线索效应与误导效应分开报告：B、H、A = B − H，并直接检验 A_C − A_K（agent2 2026-10-08）。
- 剂量曲线：K30、C16 上的全部统计量。
- 六选一：六类选项的概率变化（完好模型近乎满分）。
