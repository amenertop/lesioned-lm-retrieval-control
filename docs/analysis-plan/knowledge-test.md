# 分析计划：知识侧与双向分离在保留测试集上的检验

状态：用户已在对话中确认（2026-09-28：以 8 个组件为主判定、4 个只报告；两档判定；其余按默认）。已按 agent2 2026-09-29 的审阅意见修改，实验三的知识条件也已在拆封前定为同一组 8 个组件；打标签 `analysis-frozen-knowledge` 后拆封一次。脚本：`experiments/e2_confirm/run_dissociation_test.py`。

## 1. 检验什么

`spec.md` 中 H2 的两个差值（关卡 G3）。两者都成立，才算“双向分离”：关掉控制组件主要伤控制，关掉知识组件主要伤知识。

- **ΔC（控制差）**：在 M1 保留的颜色、尺寸题上，控制组的控制效应减知识组的控制效应。
- **ΔF（词频差）**：在看定义说词（命名测验）的保留题上，知识组的知识效应减控制组的知识效应。

## 2. 模型、组件和关法

- 模型：Qwen3-30B-A3B-Instruct-2507，float16，输出层用 float32 计算（ADR 0003、0004）。
- 关法：完全均值消融（α = 0），均值来自中性文本（`@0d7cf23__42ae809__fp16.pt`），与两次筛选和控制侧检验相同。
- 控制组：`outputs/e1_screen/qwen3-30b-a3b-instruct/screen/selection.json` 中的 4 个注意力头（head:9:15、head:27:9、head:25:24、head:24:5），与控制侧检验相同，由 `load_selection` 核对哈希。
- 知识组（主判定）：知识筛选（`outputs/e3_knowledge/qwen3-30b-a3b-instruct/screen/`）中逐个真实消融核实后知识效应最大的 8 个，即 spec G2 预先规定的一次扩大：expert:46:61、expert:46:101、head:37:24、expert:45:32、expert:45:48、expert:43:70、expert:42:115、expert:45:93。脚本从 `screen.csv` 重新排出前 8 个，与这份名单逐一核对。
- 知识组（只报告）：其中前 4 个，即 `selection.json` 中的原始知识组。
- 来源：两组知识组件都是在提交 `d755a4e` 时、在第一批 300 道题的筛选集上挑出的（当时 `items.csv` 的 SHA-256 为 `44155723550783c38cee4f2a08ca7a2c84c40c137c6a9dfeea68600d5f705c96`，冷门和常见的分界线为 Zipf 2.99965）。之后加入第二批 300 道题，但组件没有在 600 道题上重新挑选（agent2 2026-09-28 意见）。

## 3. 数据

- 冻结时的文件哈希（SHA-256）：命名测验 `items.csv` `589708d96baf5979dc35139d4cddf0f13ca549c9800ef8fabb6c2874fb022398`（筛选、开发、保留的划分是这个文件的 split 列，没有单独的划分文件），`demos.csv` `9bed1955fedc324be95e8b87ce7b4841e42b66c85535319dc36d22d7fc381b99`；M1 `items.csv` `2ac9cb4fe51bf6090a8bfe2e9c612c60dfa45cdbd2d6d81860aebd6531a379e6`，`split.csv` `780ffb3f7d274874e25a3beedabaf3cc2f5bffc1b22c5b16017f78f0e9436675`。运行记录同时写入这四个哈希。
- **命名测验保留集**：`data/materials/m3_knowledge/items.csv` 中 split 为 test 的 240 道题，每个词频档 40 道，两批各 120 道。这些题从未在任何组件被关掉的情况下算过分。有效性检查（`reports/explore/qwen_knowledge_items_check_600.json`）看过完好模型在全部 600 道题上的分数，但没有据此删改任何一道题。
- **M1 保留集**：主判定只用颜色题和尺寸题（63 道，其中强干扰 30 道）。这批题在控制侧检验时已打开过一次（`analysis-frozen-control`），所以控制组那一半已知：控制效应 4.05，区间 [2.41, 5.66]。知识组在这批题上的结果是新的。字符串题和同义判断题只报告。
- 按现有出题规则，词库已不够再出一份同样规格的命名保留集：Zipf 4 以上一档只剩约 40 个没用过的合格词，Zipf 3.5 至 4 一档只剩约 20 个。所以这是知识侧唯一一次正式检验。

## 4. 统计量

- 命名测验的损伤：每道题完好模型的答案对数概率（自然对数）减去消融后的值。打分方式与知识筛选相同：批量 16、11、7 各算一次，取平均。
- 知识效应：Zipf 低于 2.99965 的题的平均损伤，减去其余题的平均损伤。分界线沿用知识筛选时定下的值，不重新计算。
- ΔF = 知识组的知识效应 − 控制组的知识效应。两组在同一批题上计算，配对。每道题自成一组，重抽样 10,000 次，取 95% 区间。
- M1 的损伤和控制效应与控制侧检验相同（`damage.effects`，打分用 `prefix_avg3`）。ΔC = 控制组的控制效应 − 知识组的控制效应，配对，按概念组重抽样 10,000 次。

## 5. 判定（两档，2026-09-28 用户决定）

两个差值用同一条规则，门槛 0.20。0.20 在 M1 上是 logit；在命名测验上是答案对数概率，意思是冷门词的答对概率比常见词多掉约 18%（按比例算）。两者单位不同，数值不能互相比较，也不能把 0.20 说成两种题型上相同大小的效应；论文分别写明单位和判定标签（agent2 2026-09-29 意见）。

| 区间 | 判定 |
| --- | --- |
| 下界高于 0.20 | 支持，达到预设的最小有意义效应 |
| 下界高于 0，上界低于 0.20 | 支持，存在但很小 |
| 下界高于 0，区间跨过 0.20 | 支持，大小未定 |
| 下界不高于 0，上界低于 0.20 | 排除 |
| 其余 | 证据不足 |

- **H2（双向分离）**：两个差值都“支持”才算成立；两个都“排除”为排除；其余为证据不足。只有一个差值成立时，按 spec G3 的分支写：这一类的贡献可以定位，另一类在本次检验中没有定位到。本次没有定位到，不能推出另一类计算在模型中是分布式的。
- **与 spec 的差别**：spec 原要求两个差值的下界都高于 0.20 logit 才算支持。这一规则在拆封之前、看过开发集结果之后改为两档，理由是知识侧的测量从 M1 同义判断（logit）换成了命名测验（对数概率），0.20 原本不是为这个测验定的。论文如实交代改动，并同时报告下界是否超过 0.20。
- **多重比较**：H2 要求两个差值同时成立，这本身比单独检验一个更严（交并检验），所以不另做校正。spec 原写的五项 Holm 校正不在这里使用，论文中交代。
- spec 原写用混合模型估计；这里与控制侧检验一致，用按组重抽样的区间。

## 6. 只报告、不作门槛

- 知识组自身：知识效应（用同样的两档标签，只作描述）、连续斜率、整体命名损伤；在 M1 上的控制效应、语义题损伤和字符串题损伤。这样读者能看到命名损伤是不是“普遍变差”（agent2 2026-09-28 意见）。
- 控制组自身：在命名测验上的知识效应和整体命名损伤。spec 的“H2 附加”：控制组对 M1 弱干扰颜色、尺寸题的平均损伤，以及对常见一半命名题的平均损伤，报告区间上界是否低于 0.10（等效检验，不影响判定）。
- 4 个知识组件：以上全部数值，包括它们的 ΔF、ΔC，不作判定。
- 与 200 组随机组件比较：随机组与 8 个知识组件一一对应，同类、同层，专家还按路由频率匹配，并排除知识组和控制组的组件。随机组只在命名保留集上计算，为节省 GPU，每组只用批量 16 算一次，与同样只算一次的完好模型分数相减。报告有多少组的知识效应达到或超过知识组（主打分），以及经验 p 值 (1 + k) / 201。随机组数值波动更大，更容易达到目标，所以这个比较偏保守。知识组在同样只算一次时的值也一并报告。经验 p 值只作描述，不是判定依据，也不能代替 ΔF、ΔC 的区间（agent2 2026-09-29 意见）。
- 复现核对：控制组在 M1 保留集上的控制效应，与控制侧检验的 4.05 比较。

## 8. 之后

拆封之后不再根据保留集重新挑选组件、改分界线或改统计量。实验三的知识损伤条件沿用这里的 8 个组件，不论拆封结果如何都不改用 4 个（2026-09-29 用户决定，拆封前确定；`docs/plans/experiment3-protocol.md` 第 3 节）；如果 H2 只有一类成立，按 spec G3 的分支处理。之后在筛选集、开发集上的探索照常进行，但凡是这里没有写到的结论，都标为探索性结果。
