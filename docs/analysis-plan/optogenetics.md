## 5. 统计量

- 各格式的损失 = 完好减损伤，正数表示变差（`analyze_optogenetics.losses`）：
  - 说词：无提示时目标词的整词对数概率；
  - 六选一：正确字母的 logit 差额，6 种排列平均；
  - 词选定义：差额，两种顺序平均；
  - 另有给选项说词、照抄。
- 提示类量 = 损伤后减完好，基线为“示范带提示的无提示条件”，与实验三相同：
  - B 为正确提示获益的变化；
  - H 为误导伤害的变化；
  - ΔR 为提示依赖（正确提示与误导提示之差）的变化。
- 交互量 = L(K8 + C4) − L(K8) − L(C4)，按概念计算。
- 区间：按概念有放回重抽样 10,000 次，种子 0，取百分位 95% 区间。160 个概念与 100 个提示概念各用一套重抽样计数，按这个顺序从同一个随机数生成器抽出（`lesion.e3_analysis.resample_counts`）。
- 概念的排列：按材料文件 `final_items.csv` 的行序（`m3_optogenetics_plan.confirm_ids`），不取运行记录里的顺序。重抽样计数第几列对应哪个概念由这个顺序决定；只把运行记录里的概念顺序倒过来，判定也不能变（agent3 2026-10-13，N5）。
- 单侧 p =（重抽样中不满足方向的次数 + 1）/（10,000 + 1）。
- 实现：`experiments/e3_errors/analyze_optogenetics.py --confirm`。

## 6. 判定

所有比较都是同一概念上的配对差，不比较两个独立均值的区间（agent2 2026-10-12）。

| 编号 | 统计量 | 支持的条件 | p 值 |
| --- | --- | --- | --- |
| R1 | ① K8 说词损失：α = 0 减 α = 0.75；② C4 六选一损失：α = 0 减 α = 0.75 | 两个差的区间下界都高于 0 | 两者中较大的 |
| R2 | 对每个 α ∈ {0.25, 0.5, 0.75}：K8 的说词损失、C4 的六选一损失（本组标志）；K8 的六选一损失、C4 的说词损失（对方标志） | 本组标志的区间下界都高于 0，**并且**对方标志的区间上界都低于 0.20（标志排除界值，同 S1、S2 的最小有意义效应） | 12 个部分中最大的 |
| R3 | K8 在 α = 2 时的 ΔR | 区间上界低于 0 | 单个 |
| R4 | K8 只在回答区：① 说词损失，② B，各取 α = 0 减 α = 0.75 | 两个差的区间下界都高于 0 | 两者中较大的 |
| R5 | C4 只关中段时的 H；C4 只关回答区时的 H | 中段 H 的区间上界低于 0，**并且**回答区 H 的区间下界高于 0 | 两者中较大的 |
| R6 | 交互量：① 六选一，② 说词 | 六选一交互的区间下界高于 0，**并且**说词交互的区间整个落在 ±0.20 之内 | 三个单侧 p（六选一，说词的上、下两侧）中最大的 |

- **多重比较**：R1 至 R6 为第三族，用单侧 p 做 Holm 校正。判定为“支持”需要条件满足且 Holm 校正后 p 低于 0.05；其余为“证据不足”，不设“排除”。
- **语言损失**：规则所用的状态中，若有一种在中性文本上的语言损失比完好高出 10% 以上，这条规则不作解释，记为“不解释”。阈值开卡前定死。
  - R4、R5 只关一段，普通文本没有题干、中段、回答区之分，这几种状态无法单独测语言损失。改用同组、同强度的整段损伤作上限：整段损伤关掉的位置包含分段损伤关掉的全部位置。R4 看 K8 与 K8 α = 0.75，R5 看 C4（用户 2026-10-13 决定，回应 agent3 复审 N4）。练习题上 K8、C4 整段只让语言损失上升 1.3%、1.4%；
  - 实际读的状态：R1 为 K8、K8 α = 0.75、C4、C4 α = 0.75；R2 为两组的三档调光；R3 为 K8 α = 2；R4、R5 如上；R6 为 K8 + C4、K8、C4；
  - 某个状态的语言损失缺测，不当作“未超过 10%”，这条规则记为“无法检查”。
- **判定读未舍入的数值**：区间与 0、与 ±0.20 比较时用原始数值，四位小数只用于展示。先舍入会挪动阈值，例如说词交互的区间上界 0.19996 舍入成 0.2 后就不再“落在 ±0.20 之内”（agent3 2026-10-13，N7）。
- **措辞的界限**（agent2 2026-10-12）：
  - R1 写“剂量对比”，不单凭两个端点说“连续”；四个强度的走势只作描述；
  - R2 写“在所测强度范围内，标志特异的分离”，同时报告两类损伤的实际严重程度。它只排除对方标志的实质性损伤，不证明所有行为维度都是“种类不同”；
  - R3 是外推（增益），不写成更重或更轻的病程；
  - R5 说明两个位置对同一读出方向相反，不说明所有段之间都分离；
  - R6 写“在对数几率（logit 差额）尺度上的非加性交互”，不写“相互放大”：K8 单独时六选一损失为负，双重损伤超过两者之和，但仍可能比只关 C4 轻。

## 7. 只报告，不作判定

- 调光与增益：全部强度的格式损失曲线；与 α = 0 的形状余弦；放大时冷门词与常用词的说词变化。
- 随机组：randomK_00、randomC_00 在 α = 0.5、2 的结果；随机单、双损伤的六选一交互逐组列出。只作特异性的探索性检查，不并入第三族，也不能用它们排除或证明 K × C 的特异性。
- 交互的尺度敏感性：六选一正确字母概率（6 个字母 logit 的 softmax，6 种排列平均）上的交互。练习题上完好模型的这个概率是 0.997，各损伤只降低 0.003 以内，交互接近 0。所以 R6 只能写在 logit 差额尺度上。
- 逐段：K8 的其余三段；C4 的题干、示范区，以及各段两两、三阶交互（容差 0.20 分三档：可忽略、不可加、无法判定，同练习方案第 9.4 节）。
- 救援：α = 0.25、0.5 的点，ΔR 曲线，跨概念 Spearman 相关（α = 0 的 B 与 α = 0.5 救回的说词）。
- 病程式的词频梯度（P8 (c)，2026-10-12 用户决定）：K8 在 α = 0.75、0.5、0.25、0 时，冷门与常用（Zipf 中位数分组）概念的说词损失，以及 Zipf 与说词损失的 Spearman 相关。练习题上冷门减常用依次为 0.13、0.28、0.56、0.58，区间都跨 0。
- 路由计数；语言损失；贪心生成的说对率与例句（供 P8 (d) 的例句表）。
