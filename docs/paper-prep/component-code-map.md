## 怎样使用

WR8 与 WR16、WR30 按同一提取排序扩展。SC8、SC16 按控制排序扩展。SC8 和 SC16 都含专家，不能统称控制头。SC4b 也不全是注意力头。只有明确指 SC4 时才用 control heads。

SC32 来自另一条搜索，不是把 SC4 接着加到三十二个。WR8b 与 WR8 是不同集合。WR8b 去掉共享头的条件用描述名，不能另取一个数字代号掩盖它与原组的关系。P14 的知识候选和轮毂候选保留方法名称，尚未给它们新增论文功能名。

组的身份与损伤位置分开写。例如 WR8 answer-position lesion 表示只在回答位置干预 WR8。WR8 amplification 表示放大同一组，不是新选出一组。

## 文献中的歧义

本刊 Arévalo 等 2007 用 WR 表示 word reading，另有复述文献用 WR 表示 word repetition。SCN 是 semantic control network 的既有缩写。具体全文定位见写法调研报告第二节。因此本文使用完整 WR8、SC4，在首次出现时定义为模型内按任务选出的零件组，阅读与复述写全称。模型组名不承担人脑区域对应的结论。摘要继续用描述性名称。
